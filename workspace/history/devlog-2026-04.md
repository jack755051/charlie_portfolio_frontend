## 2026-04-19 ｜ 修復 home-terminal.vue i18n 片語型別錯誤

### 1. 事件摘要
- **現象**：執行 `npm run dev` 後首頁 SSR 階段回傳 **500**，錯誤訊息 `TypeError: currentPhrase.substring is not a function`。
- **觸發來源**：`components/features/home-terminal.vue` 打字機效果模組。

### 2. 根因分析（02 Tech Lead）
- 專案啟用 `@nuxtjs/i18n`（`nuxt.config.ts:15-28`），底層 `@intlify/unplugin-vue-i18n` 在 build 期會把 `i18n/locales/*.json` 的每個葉節點字串**預編譯為 message compiler function**。
- 原實作於 `home-terminal.vue` 直接 `import zhLocale from '~/i18n/locales/zh.json'`，繞過 i18n runtime，取到的 `home.roles[0]` 為 function 而非字串。
- Function 物件無 `String.prototype.substring`，故於 `typeEffect()` 拋錯。

### 3. 技術決策（ADR）
- **選型**：採用 **`useI18n()` runtime API**（`tm()` 取訊息樹 + `rt()` 解析為字串）。
- **否決方案**：
  - 直接 type cast 成 string：僅掩蓋型別錯誤，runtime 仍為 function。
  - 將 roles 移出 i18n 以常數管理：違背既有 i18n SSOT 策略。
  - 關閉 `@nuxtjs/i18n` compilation：全站效能受損，成本不對等。
- **對齊規範**：`docs/agent-skills/04-frontend-agent.md` §3.3（服務層資料清洗）— 不應讓 UI 元件直接吃 raw i18n 資源。

### 4. 變更清單

| --- | --- | --- |

## 2026-04-19 ｜ Hero 區塊 UI/UX 全面升級（Phase 1~3 一次到位）

### 1. 背景與動機
- UI 稽核發現：手機完全看不到 Terminal 卡片（`hidden md:flex`）、僅單一 md 斷點、無 dark mode、標題平淡無視覺焦點、背景單調。
- 需對齊 2026 主流工程師作品集常見元素：gradient mesh 背景、gradient text、display/mono 字體、dark mode、micro-interaction。

### 2. 技術決策（ADR）
- **字體**：採用 **Sora**（display）+ **JetBrains Mono**（code），透過 Google Fonts 載入並以 `preconnect` 降低首載延遲；於 `tailwind.config.js` 擴充 `fontFamily.display` / `fontFamily.mono`。
- **Dark Mode**：採 Tailwind 預設 `media` 策略，跟隨作業系統偏好，**無需 JS 切換**、**無需 localStorage**，最低成本導入。
- **背景裝飾**：三顆 `blur-3xl` 模糊色塊 + `radial-gradient` dot grid pattern，以 `pointer-events-none` 防干擾點擊。
- **動效**：
  - `animate-float-slow`（blob 緩慢浮動，6s）
  - `animate-blink`（caret 閃爍，1.1s steps）
  - `animate-fade-in-up`（標籤淡入）
  - 全數支援 `prefers-reduced-motion` 關閉。
- **RWD 重構**：移除 `hidden md:flex`，改以 `grid-cols-1 md:grid-cols-2` + `order-*` 於手機將 Terminal 置於文字上方；補齊 `sm / md / lg` 斷點對字級、padding、gap 做細調。
- **Gradient Text**：標題套 `bg-gradient-to-r from-orange-500 via-rose-500 to-fuchsia-500 bg-clip-text text-transparent` + `drop-shadow` 輕發光。
- **CTA 按鈕**：`flex-wrap` 防手機擠壓；主按鈕加 `hover:-translate-y-0.5` + shadow glow；次按鈕 dark mode 補色。
- **Terminal 強化**：加入行號欄位（`select-none`）、游標 blink、hover 時 `ring-orange-500/40` 發光。

## 2026-04-19 ｜ Semantic Color Tokens 根治 Dark Mode 漆黑問題

### 1. 問題
使用者回報：系統切深色後，背景變暗但大量文字仍為深色系 → 畫面漆黑、不可讀。03 UI 掃描發現 **12 檔 `text-slate-7/8/900`、13 檔 `bg-white` 未加 `dark:` 變體**，其中 `components/layouts/AboutSection.vue`（about/experience/tech-stack/leetcode 四 section 共用標題）未改 → 一檔影響四頁。

### 2. 方案決議（ADR）
- **採 Strategy B：Semantic Color Tokens + CSS Variables（shadcn convention）**。
- 否決繼續逐行加 `dark:`（技術債複利、工程紀律負擔）。
- 否決 Strategy C 折衷（初期專案成本可承受一次到位）。
- 未來若導入 shadcn-vue，此 token 模型完全相容。

### 3. 實作重點
- 新建 `assets/css/tailwind.css` `@layer base` `:root` + `@media (prefers-color-scheme: dark)` CSS Variables。
- `tailwind.config.js` 將 `background / foreground / card / popover / primary / secondary / muted / accent / destructive / border / input / ring` 掛上 `rgb(var(--x) / <alpha-value>)`；`primary/secondary` 改為物件形式含 `foreground`。
- Migration 15+ 元件 / 4 頁；刪除先前為應急加的 `dark:` 冗餘（除 BackgroundDecor blob 刻意變體保留）。
