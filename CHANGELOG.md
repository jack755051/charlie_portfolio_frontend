# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog.

## [Unreleased] - 2026-04-16

### Added
- Added JSON single source of truth assets for site reference, portfolio projects, and LeetCode profile snapshots under `assets/data/`.
- Added JSON schema files and validation utilities for SSOT consistency under `schemas/` and `scripts/validate-json-ssot.mjs`.
- Added a scheduled GitHub Actions workflow at `.github/workflows/sync-leetcode.yml` to fetch LeetCode data daily and rewrite `assets/data/leetcode-profile.json`.
- Added frontend data composables for site reference, portfolio projects, and LeetCode profile loading.
- Added architecture and handoff documentation for the JSON SSOT migration under `docs/architecture/`.

### Changed
- Changed the frontend data flow to read static content from JSON SSOT files instead of in-file mock data stores.
- Changed portfolio pages and shared UI consumers to use composable adapters and normalized project metadata.
- Changed LeetCode rendering to consume the normalized JSON snapshot generated by sync scripts and GitHub Actions.
- Changed the Nuxt deployment pipeline to validate SSOT data before static generation and deploy from `.output/public`.
- Changed localized homepage and tech stack copy rendering to avoid HTML string injection.

### Fixed
- Fixed residual Pinia and mock-store drift by removing `stores/useMockStore.ts` and `stores/useLeetcodeStore.ts`.
- Fixed frontend type issues surfaced by Nuxt typecheck, including locale typing, project detail null safety, and JSON normalization typing.
- Fixed lint warnings and unsafe `v-html` usage in homepage and technology stack sections.
